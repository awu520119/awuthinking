这是一篇用于检查博客交互的测试文章。

## 为什么要测试

一个博客不只是首页，还包括文章列表、标签、归档、搜索和 RSS。把这些入口都走一遍，才能知道站点是否完整。

## 常见的发布流程

```bash
hugo new posts/my-post.md
hugo server -D
git add .
git commit -m "新增文章"
git push origin main
```

你也可以通过[归档页面](/archives/)查看这篇文章是否出现。

> 好的工具应该让记录变得自然，而不是让记录本身成为负担。
